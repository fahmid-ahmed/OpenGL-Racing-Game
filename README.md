# OpenGL Racing Game

A 3D racing game built with C++ and OpenGL.

## About

This project is a racing game developed as a C++ graphics programming project using OpenGL.

## Technologies Used

- C++
- OpenGL
- GLFW
- GLM
- CMake

## Features

- 3D graphics
- Real-time keyboard controls
- Racing gameplay

## Requirements

- A C++ compiler
- CMake 3.20 or later
- GLFW
- GLM
- OpenGL
