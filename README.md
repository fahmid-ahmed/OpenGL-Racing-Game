# OpenGL Racing Game

A 3D racing game developed in C++ using OpenGL.

## Technologies Used

- C++
- OpenGL
- GLFW
- GLM
- CMake

## Features

- 3D graphics
- Real-time keyboard controls
- Racing gameplay

## Requirements

- C++ compiler
- CMake 3.20 or later
- GLFW
- GLM
- OpenGL

## Build and Run

Clone the repository:

    git clone https://github.com/fahmid-ahmed/OpenGL-Racing-Game.git
    cd OpenGL-Racing-Game

Build the project:

    cmake -S . -B build
    cmake --build build

Run the game on macOS:

    ./build/RacingGame
